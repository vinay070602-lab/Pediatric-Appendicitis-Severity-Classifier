# Pediatric-Appendicitis-Severity-Classifier
An XGBoost-based machine learning model for predicting pediatric appendicitis severity (complicated vs. uncomplicated) using the Regensburg Pediatric Appendicitis Dataset (Zenodo: 7669215). Includes data preprocessing, SMOTE for class imbalance, hyperparameter optimization, model evaluation, and SHAP-based explainability.
